# Standalone Causal Narrative Core

A small, dependency-free, model-independent library for inspectable choice-driven fictional transitions. This is runnable open-source research. It is **not** the private THE COLLECTOR AI Director.

## Purpose

Interactive stories can fail when choices lead to identical states or developers cannot explain which earlier decision caused a later event. The core records explicit state effects and reproducible causal traces.

## Reproduce the example

Requirements: Node.js 24+.

~~~sh
npm install
npm run demo:core
npm run test:core
~~~

No API key, live model, subscription or private profile is needed.

## Reuse in another project

Import from the checked-out module. No npm release has been published.

~~~js
import { inspectGraph, startSession, publicScene, choose, causalTrace } from './src/causal/index.mjs';

const graph = {
  start: 'begin',
  nodes: [
    { id: 'begin', lines: ['A door opens.'], choices: [
      { id: 'enter', label: 'Enter', next: 'inside', fact: 'You cross the threshold.', effects: { location: 'inside' } },
    ] },
    { id: 'inside', lines: ['The door closes behind you.'], choices: [] },
  ],
};

if (!inspectGraph(graph).valid) throw Error('Invalid graph');
const first = startSession(graph);
console.log(publicScene(graph, first));
console.log(causalTrace(choose(graph, first, 'enter')));
~~~

## Contract

* inspectGraph reports invalid edges, duplicate choices, invalid scalar effects, unreachable scenes and structurally identical options.
* startSession creates a local state and empty event ledger.
* publicScene reveals the present scene and choice labels, withholding future consequences and private effects.
* choose returns a new state with an evidence event containing previous and next scalar values.
* compareChoices checks whether two actions lead to different nodes or world values without modifying the initial state.
* causalTrace provides a reproducible event summary for tests.

## Evidence and limitations

Tests check graph validation, public outcome hiding, immutable transitions, branch differences, invariance to unrelated metadata, and rejection of invalid choices. The offline demo prints different states after two choices.

The graph is written by the developer. This tool does not call a model, infer psychology, interpret astrology, store user profiles or evaluate artistic quality. Structural divergence alone does not establish originality, emotional impact or personalized causality.

## Open source roadmap

Future work: detect cycles without reachable endings, validate richer typed states, replay longer paths, test candidate graphs generated by AI, and add developer integrations. These are plans, not shipped features.
