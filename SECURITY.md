# Security and privacy

This repository is a public research prototype. Please do not publish sensitive material in issues, pull requests, test fixtures, or logs.

Do not commit:

- API tokens, passwords, private signing or encryption keys, or local `.env` files.
- Personal birth records and real private wishes.
- Encrypted private evaluation artifacts together with their decryption keys.
- Private Codex production source from a separate repository without the owner's explicit authorization.

For a sensitive finding, contact the repository maintainer privately through their GitHub profile before publishing a detailed exploit or confidential reproduction.
